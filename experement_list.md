# Следующие эксперименты с ERank

1. **Сравнить `k ≈ ERank` с классикой при одинаковом потолке MACs и  Параметров.**.Обучить архитектуры с нуля по одному рецепту и сравнить test accuracy, фактические MACs и число параметров.


2. **Найти точку стабилизации ERank и ширин.** Обучить сеть, измерить ERank каждого сужаемого слоя, задать новые ширины `k ≈ ERank` и обучить эту архитектуру с нуля. Повторить цикл с теми же настройками измерения. По раундам записывать ERank, ширины и accuracy (тут можно с первым подвязать).

3. **Проверить, как способ расчёта ERank влияет на выбор ширин ViT-Tiny.** Сравнить шесть вариантов расчёта ERank на одних и тех же активациях и обучить полученные архитектуры с нуля при одинаковом потолке параметров. Для первого MLP-блока оценка ранга центрированных активаций составила 52 по собственным значениям ковариации и 310 по сингулярным значениям, а при бюджете 50% параметров точность шести вариантов составила 81,52–81,87%.

4. **Сравнить факторизацию по ERank с равномерным сужением MLP в ViT-Tiny.** Обучить с нуля полную модель, модель с низкоранговой факторизацией выходной матрицы `fc2` и модель с уменьшением ширины всех MLP с 768 до 192. На слайде сопоставить точность, число параметров и MACs. Факторизация сэкономила 4% параметров, а сужение MLP — около 50% при снижении точности на 0,34 п.п.

5. **Предсказывает ли низкий ERank, какой слой легче сжать?** Поочерёдно сужать по одному MLP-блоку обученной ViT-Tiny и измерять падение точности без дообучения. На слайде показать ERank каждого блока и падение точности при одной и той же доле удалённых нейронов. У первого блока ERank был низким, но он оказался самым чувствительным к удалению нейронов.
